# Amida — Icon & Image Assets

Replace the placeholders below with the final rasterized brand assets before
launch. All assets should be saved EXIF-stripped and with hashed filenames
where user-facing.

## Required files

| File                          | Dimensions | Purpose                          |
|-------------------------------|-----------:|----------------------------------|
| `icon-192.png`                | 192×192    | PWA manifest icon                |
| `icon-512.png`                | 512×512    | PWA manifest icon (maskable)     |
| `apple-touch-icon-180.png`    | 180×180    | iOS home-screen                  |
| `favicon.png`                 |  32×32     | Browser tab                      |
| `logo-sage.svg`               | vector     | Header wordmark (sage on cream)  |
| `logo-cream.svg`              | vector     | Footer wordmark (cream on sage)  |
| `og-default.png`              | 1200×630   | Social meta default              |

## Image-mask assets

Compound-name images for GLP products live under
`/wp-content/uploads/compound-names/` and are generated by the
`Amida_Image_Masker` class in the compliance plugin. Do NOT commit them to
git — they are runtime artifacts.
